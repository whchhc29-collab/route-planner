SETUP · 一次性配置

先接入你的高德 Key

这个页面不内置任何密钥，你需要填一个自己的高德「Web 服务」Key 才能查实时路线。
Key 只存在你本机浏览器（localStorage），不会上传给任何服务器；刷新和关掉页面都还在。
怎么拿到 Key（约 3 分钟，免费）
1. 打开 lbs.amap.com → 注册 / 登录 → 完成 个人实名认证
2. 进「控制台 → 应用管理 → 我的应用」→ 创建新应用
3. 点「添加 Key」，服务平台必须选「Web服务」
  （别选「Web端(JS API)」，两者不通用，本页要的是 Web服务）
4. 复制那串 32 位字符，粘到下面
免费 Key 有 QPS 限制，本页已做「串行 + 间隔 + 自动重试」来规避。
AI LAYER · 可选

接入任意大模型

用 OpenAI 兼容协议，任何支持的模型都能填。配好后就能用「一句话生成路线」—— 模型只负责把你的话拆成起点 / 目的地 / 偏好，路线本身仍由高德计算。
配置只存在本机浏览器。
提示：浏览器直连这些 API 需要对方支持跨域（CORS）。DeepSeek / 通义 / GLM / Kimi 通常可直接用； 本地 Ollama 需设置环境变量 OLLAMA_ORIGINS=*。 若被浏览器拦截，请换服务商或自建代理，非本页问题。
