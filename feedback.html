还没接入评论后端

本页是纯静态页面，评论需要一个免费的后端来存取。Supabase 免费版即可。请按下面两步操作，然后把 Project URL 和 anon public key 填进本文件顶部的两个常量（SUPABASE_URL / SUPABASE_ANON）后重新部署。

  1. 在 Supabase 新建项目（Region 选 Singapore 即可），进入 SQL Editor，运行下面这段建表语句：
create table if not exists public.comments (
  id bigint generated by default as identity primary key,
  thread_id text, parent_id bigint, name text,
  content text not null, created_at timestamptz default now(),
  status text not null default 'pending'
);
alter table public.comments add column if not exists status text not null default 'pending';
alter table public.comments enable row level security;
drop policy if exists "read all" on public.comments;
drop policy if exists "insert all" on public.comments;
create policy "read approved" on public.comments
  for select using (status = 'approved');
create policy "insert pending" on public.comments
  for insert with check (
    status = 'pending'
    and char_length(content) between 1 and 2000
    and content !~* '(加微信|加薇|代购|发票|办证|博彩|赌博|裸聊|约炮|援交|傻逼|煞笔|草泥马|操你|http://|https://|www\.)'
  );
  1. 在 Project Settings → API 复制 Project URL 与 anon public key，填入本文件顶部的两个常量。

说明：anon key 是设计上可公开的钥匙（策略只允许访客「读已审核通过的留言」和「新增待审核的留言」，任何人都不能删改或自行放行）。
